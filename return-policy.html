Return & Exchange Policy

If Jaman Store supplies the wrong product or the wrong mattress size for the order you placed, you can request an exchange. The return is handled through a designated Jaman Store pick-up/return station.

When an exchange applies

Wrong product supplied

If the product delivered is different from the product recorded on your order, submit a return request.

Wrong size supplied

If the product is correct but the mattress size supplied differs from the size on your order, submit a return request.

Important: This policy is for errors made in supplying the ordered product or size. A customer who selected the wrong size or changed their mind is not automatically covered by this exchange process.

Key conditions

  • Report the issue within 48 hours of delivery or collection.
  • Submit the return request using your order reference and the phone number used for the order.
  • The mattress should be unused, clean and undamaged, and should not have been slept on, altered or deliberately damaged.
  • Return the item to the designated Jaman Store pick-up/return station after the request is approved.
  • Jaman Store will verify the returned item before releasing the replacement.
  • Where the exact replacement is unavailable, Jaman Store will contact the customer to agree the available exchange arrangement.

How the exchange works

  1. Submit the return/exchange request below.
  2. Jaman Store reviews the order and the reason for the request.
  3. If approved, Jaman Store confirms the designated return station and return instructions.
  4. Customer returns the mattress/product to the designated station.
  5. Jaman Store verifies the returned item and prepares the correct product or size.
  6. The exchange is completed and the request is marked complete.
